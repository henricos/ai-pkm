<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Head bootstrap script -> DOM raiz | O script pre-paint não pode vazar tema para fora do viewer |
| DOM raiz -> subtree do viewer | O CSS precisa respeitar escopo local mesmo lendo um atributo do root |
| localStorage -> bootstrap | Valor inválido ou indisponível não pode quebrar renderização |
| React hydration -> themed viewer | O ganho visual não pode custar mismatch ou render inicial inconsistente |

## STRIDE Threat Register

| Threat ID | Severity | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-06-01 | high | Tampering | layout/bootstrap | mitigate-blocking | Separar atributo de bootstrap do atributo efetivo do viewer |
| T-06-02 | high | Tampering | hydration | mitigate-blocking | Manter `DEFAULT_THEME` como estado inicial do React e usar bootstrap apenas como camada visual |
| T-06-03 | medium | Denial of Service | localStorage access | mitigate | `try/catch` e validação explícita de tema |
| T-06-04 | medium | Spoofing | CSS scope | mitigate | Ancorar todos os seletores de bootstrap ao escopo explícito do viewer |
</threat_model>
