<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Git tag -> CI workflow | Uma tag de release aciona publicação externa |
| CI runner -> GHCR | O job recebe permissão para publicar imagem no registry |
| Git history -> release eligibility | Apenas commits pertencentes a `main` podem originar release oficial |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-04 | Spoofing | release trigger | mitigate | Disparar só em `push` de tag `v*.*.*` e validar que o SHA pertence a `origin/main` |
| T-08-05 | Tampering | image tags/labels | mitigate | Comparar tag Git com `package.json` e publicar labels OCI explícitas no workflow |
| T-08-06 | Repudiation | published artifact | mitigate | Publicar `vX.Y.Z` + `latest` e anexar `version`, `revision` e `source` ao artefato |
| T-08-07 | Information Disclosure | registry permissions | accept | O pacote será público por requisito do milestone; limitar permissões do workflow a `contents: read` e `packages: write` |
</threat_model>
