**1. Criar docs/dev-setup.md:**

O documento deve cobrir em pt-BR:
- Pré-requisitos: Node.js >=20.9.0, npm, repositório pkm disponível por path local
- Clone e instalação: `git clone`, `npm install`
- Configuração do `.env.local`: copiar `.env.example`, preencher cada var com exemplo
  - PKM_PATH: explicar que deve ser absoluto (ex: `/home/user/pkm` ou `$(pwd)/pkm` se o pkm/ está na raiz do projeto)
  - AUTH_USERNAME: qualquer string (ex: `curator`)
  - AUTH_PASSWORD: mínimo 8 chars (ex: não revelar valor real — apenas descrever requisito)
  - NEXTAUTH_SECRET: comando para gerar `openssl rand -base64 32`
  - NEXTAUTH_URL: `http://localhost:3000` para dev local
- Executar em dev: `npm run dev`
- Verificação: abrir http://localhost:3000 → deve redirecionar para /login
- Aviso de segurança (per RESEARCH.md Security Domain):
  - A comparação de credenciais é string simples — suficiente para uso local/dev
  - Não expor esta aplicação publicamente sem adicionar rate limiting e hashing de senha
  - NEXTAUTH_SECRET deve ter ≥32 chars aleatórios — nunca usar valor previsível
  - `.env.local` nunca deve ser commitado (já está no .gitignore)
- Nota sobre os índices: a aplicação lê `index/topicos.json` e `index/grupos.json` da raiz do projeto `ai-pkm`, não do `pkm/` montado. Se rodar de outro diretório, o CWD precisa ser a raiz do `ai-pkm`.
- Troubleshooting: erros comuns (PKM_PATH relativo, NEXTAUTH_SECRET curto, CWD errado)

**2. Criar src/app/page.tsx** (home autenticada):

```typescript
import { auth } from "@/lib/auth";
import { redirect } from "next/navigation";
import { FsItemRepository } from "@/lib/pkm/fs-item-repository";

/**
 * Home page — requer autenticação.
 * Exibe lista de tópicos como smoke test do read model.
 * Fase 2 substituirá por shell de navegação completa.
 */
export default async function HomePage() {
  const session = await auth();
  if (!session) redirect("/login");

  const repo = new FsItemRepository();
  const topics = repo.listTopics();

  return (
    <main className="min-h-screen bg-surface p-8">
      <div className="max-w-2xl mx-auto">
        <header className="mb-8">
          <h1 className="text-[1.5rem] font-medium tracking-[-0.01em] text-on-surface mb-1">
            ai-pkm
          </h1>
          <p className="text-[0.875rem] text-on-surface/60">
            Autenticado como {session.user?.name}
          </p>
        </header>

        {/* Read model smoke test — Fase 2 substituirá por shell de navegação */}
        <section>
          <h2 className="text-[0.6875rem] font-semibold uppercase tracking-[0.05em] text-on-surface/60 mb-4">
            Tópicos ({topics.length})
          </h2>
          <ul className="space-y-2">
            {topics.map((topic) => (
              <li
                key={topic.id}
                className="bg-surface-container-lowest p-4 rounded-sm shadow-ambient"
              >
                <span className="text-[0.875rem] font-medium text-on-surface">
                  {topic.id}
                </span>
                <p className="text-[0.75rem] text-on-surface/60 mt-0.5">
                  {topic.descricao}
                </p>
              </li>
            ))}
          </ul>
        </section>
      </div>
    </main>
  );
}
```

PROIBIÇÕES (per DESIGN.md):

- Não usar text-slate-*, bg-white literal — apenas tokens custom
- Não usar borders visíveis — separação por tonal shift (bg-surface-container-lowest sobre bg-surface)
