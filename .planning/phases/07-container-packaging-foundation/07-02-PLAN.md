<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build context -> image | Dados dinamicos e segredos nao podem entrar na imagem final |
| Host filesystem -> container mounts | `pkm` e `index` entram por volume externo, nao por copia na imagem |
| Compose config -> app bootstrap | A app deve receber paths explicitos e falhar cedo se a configuracao estiver errada |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04 | Information Disclosure | build context | mitigate | Excluir `pkm`, `index` e envs locais do contexto de build |
| T-07-05 | Tampering | dynamic mounts | mitigate | Declarar mounts externos explicitos para `pkm` e `index` |
| T-07-06 | Elevation of Privilege | container runtime | mitigate | Rodar como usuario nao-root |
| T-07-07 | Denial of Service | compose bootstrap | mitigate | Evitar defaults silenciosos e usar fail-fast do runtime |
</threat_model>
