<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host filesystem -> container `/data/pkm` | O acervo privado entra por montagem externa e nao pode ser copiado para a imagem |
| Operator env file -> compose runtime | Credenciais e paths precisam ser explicitos e sem defaults perigosos |
| Compose contract -> app bootstrap | O runtime deve falhar por env invalida em vez de seguir com estado parcial |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Tampering | compose volume mount | mitigate | Fixar bind mount para `/data/pkm` e injetar `PKM_PATH` explicitamente sem hard-code no codigo |
| T-07-06 | Information Disclosure | image/runtime boundary | mitigate | Manter `pkm` apenas como volume externo e nunca no contexto da imagem |
| T-07-07 | Denial of Service | compose bootstrap | mitigate | Evitar defaults silenciosos e delegar fail-fast a `src/lib/env.ts` |
| T-07-08 | Spoofing | health endpoint | accept | Nao adicionar healthcheck sem endpoint seguro e isento de auth/proxy na Phase 7 |
</threat_model>
