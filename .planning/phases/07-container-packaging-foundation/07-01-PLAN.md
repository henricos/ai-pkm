<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build context -> imagem final | Arquivos sensiveis ou desnecessarios nao podem entrar na imagem distribuivel |
| Runtime env -> processo Node | Validacao de env deve continuar centralizada e falhar cedo sem scripts paralelos |
| Runtime filesystem -> codigo Node | `index/` precisa existir no cwd do container para nao quebrar leitura server-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Information Disclosure | build context | mitigate | Excluir `.env.local`, `.git`, `pkm/` e lixo de build no `.dockerignore` |
| T-07-02 | Elevation of Privilege | runtime container | mitigate | Definir usuario nao-root e evitar toolchain de build na imagem final |
| T-07-03 | Denial of Service | env bootstrap | mitigate | Reusar `src/lib/env.ts` como ponto unico de fail-fast sem shell wrapper duplicado |
| T-07-04 | Tampering | standalone tracing | mitigate | Incluir explicitamente `index/**/*` no contrato de build e copia da imagem final |
</threat_model>
