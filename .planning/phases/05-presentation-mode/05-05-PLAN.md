  <files>src/components/viewer/laser-pointer-overlay.tsx</files>
  <action>
    Substituir a funcao `renderTrail()` inteira pela implementacao abaixo. O objetivo e eliminar o efeito de "pontos/contas" causado pelos `strokeLinecap="round"` em segmentos individuais de espessura variavel, usando um unico elemento `<path>` SVG com curvas smooth cubic bezier (comando `S`) passando por todos os pontos do rastro.

    Estrategia de renderizacao:
    - Rastro com 1 ponto: manter o `<circle>` atual (sem alteracao).
    - Rastro com 2+ pontos: construir um unico `<path>` SVG usando smooth cubic bezier.
      - Montar a string `d` com `M x0 y0` seguido de `S cx cy x y` para cada ponto subsequente.
      - Para os pontos de controle do smooth bezier, usar a reflexao automatica do comando `S` (o navegador calcula os handles).
      - Alternativa mais simples e igualmente valida: usar `L` (lineto) para 2 pontos e `Q`/`S` para 3+.
    - Opacidade: variar por posicao relativa no rastro (cauda = 0.1, ponta = 0.9), aplicada como atributo `opacity` no `<path>` unico ou via `linearGradient` SVG inline.
    - Espessura: usar `strokeWidth` fixo de `MAX_STROKE_WIDTH` no path unico (sem variacao por segmento — a variacao de espessura por segmento era a causa dos caps visiveis).
    - `strokeLinecap="round"` e `strokeLinejoin="round"` no path para suavidade nas extremidades reais (inicio e fim do traço, nao entre segmentos).
    - `fill="none"` obrigatorio no path.
    - `stroke="#ef4444"` mantido.
    - Manter `data-testid="laser-trail-point"` no elemento `<path>` para compatibilidade com os testes existentes.

    Implementacao de referencia para a funcao `renderTrail()`:

    ```tsx
    const renderTrail = () => {
      if (trail.length < 2) {
        if (trail.length === 1) {
          return (
            <circle
              key={trail[0].id}
              data-testid="laser-trail-point"
              cx={trail[0].x}
              cy={trail[0].y}
              r={MAX_STROKE_WIDTH / 2}
              fill="#ef4444"
              opacity={0.9}
            />
          );
        }
        return null;
      }

      // Construir path bezier passando por todos os pontos
      const points = trail;
      let d = `M ${points[0].x} ${points[0].y}`;

      if (points.length === 2) {
        d += ` L ${points[1].x} ${points[1].y}`;
      } else {
        // Smooth cubic bezier: S usa reflexao automatica do handle anterior
        // Para o segundo ponto, forcar Q com midpoint como controle
        const mid1x = (points[0].x + points[1].x) / 2;
        const mid1y = (points[0].y + points[1].y) / 2;
        d += ` Q ${points[0].x} ${points[0].y} ${mid1x} ${mid1y}`;
        for (let i = 1; i < points.length - 1; i++) {
          const mx = (points[i].x + points[i + 1].x) / 2;
          const my = (points[i].y + points[i + 1].y) / 2;
          d += ` Q ${points[i].x} ${points[i].y} ${mx} ${my}`;
        }
        d += ` L ${points[points.length - 1].x} ${points[points.length - 1].y}`;
      }

      // Opacidade baseada na idade do ponto mais antigo
      const now = performance.now();
      const oldestAge = now - points[0].timestamp;
      const opacity = Math.max(0.1, 1 - oldestAge / trailDurationMs);

      return (
        <path
          key="laser-trail"
          data-testid="laser-trail-point"
          d={d}
          stroke="#ef4444"
          strokeWidth={MAX_STROKE_WIDTH}
          strokeLinecap="round"
          strokeLinejoin="round"
          fill="none"
          opacity={opacity}
        />
      );
    };
    ```

    Remover as constantes `MIN_STROKE_WIDTH` que ficarem sem uso apos a mudanca (verificar se ainda e referenciada em outro lugar antes de remover).
