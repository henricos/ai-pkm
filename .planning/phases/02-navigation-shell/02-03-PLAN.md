|----------|-------------|
| Client filter input -> rendered tree | Texto digitado pelo usuário afeta o subconjunto estrutural visível da árvore |
| Current URL -> active item highlight | O rail deriva seleção e autoexpansão da rota atual |
| Snapshot data -> icon/state rendering | A UI confia no snapshot para renderizar tipo, estado e contagens |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
