<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → preview route | Input não confiável de path e sessão para leitura de asset |
| Preview route → filesystem | Leitura de arquivo do PKM precisa respeitar auth e traversal guard |
| Viewer server component → repository | Sidecar precisa ser lido por contrato específico, sem tratar binário como texto |

## STRIDE Threat Register

| Threat ID | Severity | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-04-01 | high | Tampering | preview route | mitigate-blocking | Reusar `resolveItemPath()` e retornar 400 para traversal antes de qualquer leitura |
| T-04-02 | high | Elevation of Privilege | preview route | mitigate-blocking | Exigir `auth()` no topo do handler, igual à rota raw |
| T-04-03 | high | Information Disclosure | preview/raw split | mitigate-blocking | Separar inline e attachment em handlers distintos, sem reaproveitar `/raw` como preview |
| T-04-04 | medium | Information Disclosure | content sniffing | mitigate | Manter `X-Content-Type-Options: nosniff` e `Content-Type` explícito |
| T-04-05 | medium | Tampering | repository sidecar read | mitigate | Ler apenas o `.md` adjacente via `gray-matter`; nunca parsear o binário com UTF-8 |
</threat_model>
