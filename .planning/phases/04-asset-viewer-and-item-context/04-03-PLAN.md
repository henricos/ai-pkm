<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Viewer UI → preview route | A UI renderiza conteúdo vindo de uma rota autenticada e deve tratar preview como read-only |
| Viewer UI → repository data | Sidecar Markdown entra no painel a partir de conteúdo do PKM, sem permitir HTML arbitrário |
| User interaction → zoom controls | Controles devem permanecer mínimos e não abrir superfície de edição/manipulação fora do escopo |

## STRIDE Threat Register

| Threat ID | Severity | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-04-06 | high | Tampering | viewer-page branch | mitigate-blocking | Fazer branch por `itemKind` antes de qualquer `getItemContent()` para impedir leitura textual de binário |
| T-04-07 | high | Tampering | sidecar rendering | mitigate-blocking | Renderizar sidecar por pipeline segura de Markdown, sem `rehype-raw` e sem HTML cru |
| T-04-08 | medium | Denial of Service | image/pdf viewer | mitigate | Manter solução leve nativa, sem libs pesadas, pan livre ou chrome rico |
| T-04-09 | medium | Spoofing | unsupported fallback | mitigate | Preservar fallback claro com CTA de download no header; não mascarar formatos sem preview como sucesso |
| T-04-10 | low | Repudiation | excalidraw bonus path | accept | Preview de `.excalidraw` é bônus opcional; sem trivialidade comprovada, permanecer no fallback é o comportamento aceito |
</threat_model>
